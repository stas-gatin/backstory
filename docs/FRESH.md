# Fresh viral fakes, October 2026

After the last test (H6) and with the pipeline frozen, ten posts on X from October 2026 were checked live, from the
link alone, to see how Backstory does on news people are talking about now. They were found by an agent searching
fact-checkers' articles (real photos or videos shown with a false place, date or event; each debunked; each post
still online), and run once, all of them, with the current code. This was not pre-registered and the set is small:
it is a look at fresh posts, not a measurement. Three checks first failed on a network error and were run again.

Result: **4 of 10 caught** ("Does not fit"), the other 6 "Cannot verify". All ten are fakes, so there was
no genuine post to raise a false alarm on.
