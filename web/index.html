Backstory does not judge from the pixels. With no earlier record of the photo, the answer is “Cannot verify”, never a guess.

How a check works

  1. Hear the videoFor video posts: still frames, and what is said · Muse Voice Transcribe
  2. Read the captionPlace, event and date it claims · Muse Spark with web search
  3. Find the photos in the postSeparates the photos in a screenshot or collage · SAM 3.1
  4. Find the photo onlinePages that show this exact image · reverse image search
  5. Check look-alikesWhen exact copies are scarce, compares similar images with the post · Muse Spark
  6. Date every copyFirst Internet Archive capture of each page and image file
  7. Read each pageHow it describes the photo · Muse Spark
  8. Apply the date ruleA copy older than the claimed date rules the caption out
  9. JudgeWeighs the evidence and must cite it · Muse Spark
  10. CriticChecks every citation and can send the judge back · Muse Wonder
