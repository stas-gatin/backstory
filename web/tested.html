How accurate is it?

Measured on photos fact-checkers debunked and on 207 real posts on X. Before each run, the pass rule was written down (and, from Test G on, committed); afterwards, the result was reported against that rule, including when it failed. A version is measured once, on data it has never seen; a fix is measured again on new data.
